# 🍽️ FoodLens

AI 음식 이미지 분석 기반 영양성분표 제공 웹 서비스 — 과제용 시제품

## 1. 프로젝트 개요

음식 사진을 업로드하면 사전 학습된 음식 이미지 분류 AI가 음식의 종류를 예측하고,
예측 결과를 바탕으로 영양성분표를 보여주는 Streamlit 웹 애플리케이션입니다.

### 핵심 흐름

사진 업로드
→ AI 이미지 분류
→ 음식 종류 예측
→ 영양 DB 검색
→ 영양성분표 출력

## 2. 실행 방법

Python 3.10 이상을 권장합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 사진을 업로드하고 **AI로 음식 분석하기**를 누릅니다.

> 첫 실행에서는 Hugging Face의 사전 학습 모델을 내려받기 때문에 시간이 조금 걸릴 수 있습니다.

## 3. 기술 스택

- Python
- Streamlit
- Hugging Face Transformers
- Food-101 기반 사전학습 이미지 분류 모델
- Pandas
- Pillow

## 4. 프로젝트의 AI 처리 방식

이 프로젝트는 직접 딥러닝 모델을 처음부터 학습하지 않고,
이미 학습된 음식 이미지 분류 모델을 활용하는 방식으로 구현했습니다.

1. 사용자가 음식 사진을 업로드합니다.
2. 이미지 분류 모델이 사진을 입력으로 받습니다.
3. 모델은 음식 종류별 예측 확률을 계산합니다.
4. 가장 높은 확률의 음식 종류를 선택합니다.
5. 해당 음식에 대응하는 영양 데이터를 검색합니다.
6. 사용자가 보기 쉬운 영양성분표로 출력합니다.

## 5. 현재 시제품의 한계

현재 영양 데이터는 과제 시연을 위한 예시 데이터입니다.
실제 음식의 영양성분은 음식의 양, 재료, 조리방법 등에 따라 달라질 수 있습니다.

또한 한 장의 사진만으로 음식의 정확한 중량이나 모든 재료를 알아내기는 어렵습니다.

## 6. 향후 발전 방향

- 식품의약품안전처 또는 공공 식품영양 DB/API 연동
- 음식의 종류뿐 아니라 음식의 양(중량) 추정
- 여러 음식이 함께 있는 사진에서 각각 인식
- 하루 식단 기록 및 누적 영양정보 제공
- 칼로리/나트륨/당류 등의 섭취량 그래프
- 사용자 목표에 따른 식단 추천
